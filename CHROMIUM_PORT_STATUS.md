## Conversion behavior in the source

`BrowserView` receives active-renderer selection changes, debounces for 180 ms, reads the selected frame's screen-space bounds and asks an isolated world to run the embedded pure conversion rules. It positions a compact EmberGlass bubble inside the requesting content surface, displays original/converted values and Copy, and hides on selection clear, navigation, tab switch, copy and destruction. Layout updates the placement. Appearance settings expose enable, currency, temperature, distance, weight, volume, clock and time zone. Only a recognized foreign currency requests the fixed EUR rate table; no selection text or page URL is sent. A 12-hour table is cached in profile preferences. Private profiles remain isolated.
